# Laporan proyek

- `workflow_validation.json`: konfigurasi, versi dependensi, tuning, dan metrik evaluation hasil training.
- `workflow_evaluation.csv`: label aktual serta prediksi baseline dan stack pada evaluation.
- `workflow_tests.txt`: hasil pengujian kode.
- `figures/`: visualisasi EDA, evaluasi, dan distribusi submission.

Laporan workflow dibuat dengan menjalankan notebook pemodelan atau `python -m scripts.workflow`.
Model dan cache preprocessing disimpan secara lokal, sedangkan laporan dapat disertakan dalam Git.
